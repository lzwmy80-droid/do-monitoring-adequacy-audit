# Independent MDDNR continuous-DO discovery set

Status: `download_complete`.

These are 15-minute Maryland DNR continuous-monitoring records delivered by the public MARACOOS ERDDAP service. The associated Data.gov catalog record marks the dataset public and CC0.

Frozen availability search: June 1–September 1, testing years 2025 through 2017 in descending order within each metadata time range.

The station rule was locked before DO values were inspected: alphabetical dataset order, explicit Bottom/Surface depth-pair exclusion, then the most recent candidate year with at least 5,000 rows.

Selected station datasets: 8.

This download establishes an independent data universe. It does not by itself establish QC sufficiency, a physical slope bound L, a deterministic sensor error epsilon, or a continuous environmental truth.
